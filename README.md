## 🚀 Cara Publish ke GitHub Pages

Jika repositori ini adalah `aldinosaid.github.io`, ikuti langkah berikut untuk mempublikasikannya ke internet:

1. **Inisialisasi & Commit Git (jika belum)**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio website"
   ```

2. **Hubungkan dengan Repositori GitHub**:
   Pastikan Anda telah membuat repositori baru di GitHub dengan nama:
   `aldinosaid.github.io` (harus berstatus **Public** jika menggunakan akun GitHub gratis).
   ```bash
   git branch -M main
   git remote add origin https://github.com/aldinosaid/aldinosaid.github.io.git
   git push -u origin main
   ```

3. **Cek Pengaturan GitHub Pages**:
   - Buka repositori Anda di GitHub: `https://github.com/aldinosaid/aldinosaid.github.io`
   - Masuk ke tab **Settings** -> **Pages**.
   - Pada bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**.
   - Pilih Branch: `main` dan folder: `/ (root)`, lalu klik **Save**.
   - Dalam beberapa menit, website Anda akan aktif dan dapat diakses di:
     👉 **`https://aldinosaid.github.io/`**
